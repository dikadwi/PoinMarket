# Proses Bisnis PoinMarket

## 1. Manajemen Poin Akademik

### 1.1 Pemberian Poin oleh Dosen
1. **Proses Inisiasi**
   - Dosen login ke sistem
   - Akses menu pemberian poin
   - Pilih mahasiswa target

2. **Kriteria Pemberian Poin**
   - Keaktifan di kelas
   - Prestasi akademik
   - Partisipasi kegiatan
   - Pencapaian khusus

3. **Validasi dan Konfirmasi**
   - Verifikasi jumlah poin
   - Input keterangan/feedback
   - Konfirmasi pemberian
   - Notifikasi ke mahasiswa

### 1.2 Pengelolaan Poin oleh Mahasiswa
1. **Monitoring Poin**
   - Cek saldo poin
   - Riwayat perolehan
   - Detail transaksi
   - Status validasi

2. **Penggunaan Poin**
   - Pembelian produk
   - Booking konsultasi
   - Penukaran reward
   - Transfer poin

## 2. Sistem Marketplace

### 2.1 Manajemen Produk

2. **Pengelolaan Inventori**
   - Update stok

1. **Pembelian Produk**

2. **Penyelesaian Transaksi**

   - Pencatatan riwayat
