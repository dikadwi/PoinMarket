## 1. Pendahuluan

### 1.1 Tentang PoinMarket
PoinMarket adalah sistem manajemen poin dan marketplace terintegrasi untuk lingkungan akademik. Sistem ini memungkinkan mahasiswa menggunakan poin yang diperoleh dari aktivitas akademik untuk bertransaksi di marketplace internal.

### 1.2 Persyaratan Sistem
- Browser: Chrome/Firefox/Safari versi terbaru
- Internet: Koneksi stabil
- Resolusi minimal: 1024x768

### 1.3 Akses Sistem
- URL: https://poinmarket.kampus.ac.id
- Gunakan kredensial yang diberikan oleh admin

## 2. Panduan Per Role

### 2.1 Superadmin

#### Manajemen User
1. Buka menu "User Management"
2. Untuk menambah user:
   - Klik "Tambah User"
   - Isi form dengan lengkap
   - Pilih role yang sesuai
   - Klik "Simpan"

#### Konfigurasi Sistem
1. Buka menu "System Config"
2. Tersedia pengaturan untuk:
   - Email sistem
   - Batas transaksi
   - Parameter poin
   - Notifikasi

#### Monitoring
1. Buka menu "Monitoring"
2. Lihat statistik real-time
3. Export laporan dalam format CSV/PDF

### 2.2 Admin

#### Manajemen Produk
1. Buka menu "Produk"
2. Untuk menambah produk:
   - Klik "Tambah Produk"
   - Isi detail produk
   - Upload foto
   - Set harga & stok
   - Klik "Simpan"

#### Transaksi
1. Buka menu "Transaksi"
2. Filter berdasarkan:
   - Status
   - Tanggal
   - User
3. Proses/approve transaksi

### 2.3 Dosen

#### Pemberian Poin
1. Buka menu "Manajemen Poin"
2. Pilih kelas/mahasiswa
3. Input jumlah poin
4. Tambah keterangan
5. Klik "Berikan Poin"

#### Evaluasi
1. Buka menu "Evaluasi"
2. Pilih kriteria penilaian
3. Input nilai/feedback
4. Submit evaluasi

### 2.4 Mahasiswa

#### Marketplace
1. Browse katalog produk
2. Filter berdasarkan:
   - Kategori
   - Harga
   - Ketersediaan
3. Klik produk untuk detail
4. Tambah ke keranjang
5. Checkout & konfirmasi

#### Wallet
1. Buka menu "Wallet"
2. Lihat:
   - Saldo poin
   - Riwayat transaksi
   - Pending transactions

## 3. Fitur Umum

### 3.1 Notifikasi
- Notifikasi real-time di pojok kanan atas
- Klik icon untuk melihat detail
- Tandai sebagai sudah dibaca

### 3.2 Profile
1. Klik nama user di header
2. Update informasi:
   - Password
   - Email
   - Foto profil
   - Preferensi notifikasi

### 3.3 Riwayat
- Semua aktivitas tercatat
- Filter berdasarkan tanggal/tipe
- Export data jika dibutuhkan

## 4. FAQ

### 4.1 Umum
Q: Bagaimana jika lupa password?
A: Gunakan fitur "Lupa Password" di halaman login

Q: Berapa lama poin berlaku?
A: Poin berlaku selama status mahasiswa aktif

### 4.2 Transaksi
Q: Bagaimana jika transaksi error?
A: Hubungi admin dengan menyertakan kode transaksi

Q: Berapa lama proses transaksi?
A: Instant jika automated, max 1x24 jam jika manual

## 5. Troubleshooting

### 5.1 Masalah Login
1. Pastikan username/password benar
2. Clear cache browser
3. Gunakan browser yang didukung
4. Hubungi admin jika masih bermasalah

### 5.2 Error Transaksi
1. Screenshot error message
2. Catat kode transaksi
3. Report ke admin
4. Tunggu response max 1x24 jam
